# Apps

- [poker/](poker/): Playing Cards, a portrait mobile card game app (Texas Hold'em, Five Card Draw and Blackjack).
- [timer/](timer/): Timer, a portrait interval training app (rounds, cycles, rests, a colour per phase), with timers and a stopwatch. It still beeps and rings with the app closed or the screen off.
